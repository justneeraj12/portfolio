SYS.01

ROBOTICS · PERCEPTION · CONTROL

Vision-only leader-follower warehouse convoy

ROS 2 JAZZY · GAZEBO HARMONIC · PYTHON · YOLOv8n · OPENCV · EKF · DOCKER

Multi-robot convoy coordination using monocular pinhole geometry, wheel odometry, and a deterministic TRACK / PREDICT / SAFE STOP supervisor across isolated namespaces. Debugging RGB/BGR tensor mismatches and stale-frame timestamps produced 100% valid detections with 0.0323 m range RMSE and 0.1569° bearing MAE.

30 disturbance runs / 0 hits 23.09 ms cam-to-meas p95 61 passing CI tests
Deep architecture note

The perception failure was traced to an RGB/BGR tensor-channel mismatch and stale frame timestamps. The supervisor separates fresh vision tracking, bounded odometry propagation, and a timeout-driven zero-velocity command.

SYS.02

LINUX · SECURITY · LOCAL INFERENCE

CPU-first local face authentication for Linux

C++17 · C · PAM · QT 6 · OPENCV DNN · V4L2 · UNIX SOCKETS · LIBSODIUM

Local biometric infrastructure with a custom PAM bridge, V4L2 capture, credential-checked UNIX socket IPC, encrypted profiles, desktop enrollment, and cautious fail-closed behavior. YuNet detection and SFace 112×112 embeddings run strictly on CPU without CUDA.

6.6 ms detection / CPU 12.6 ms embedding p95 ONNX zero CUDA
Deep architecture note

A minimal C PAM client sends bounded requests to an unprivileged C++17 daemon over a mode-0600 UNIX socket with peer-credential checks. Camera access and model work stay outside the privileged authentication boundary; libsodium protects committed profiles.

SYS.03

WAYLAND · NATIVE UI · RECOVERY

Nocturne Operations Console for Hyprland

C++ · QT 6 · QT QUICK · LAYERSHELLQT · WAYLAND · DBUS · LINUX IPC

A native Wayland control surface that brings system telemetry and controls into one quiet interface. Recovery is deterministic: preflight snapshots, read-only diagnostics, and confirmation-gated rollback keep installation and upgrades reversible.

WAYLAND LayerShellQt SNAPSHOT rollback CI Ubuntu + Arch
Deep architecture note

The Qt 6 shell uses event-driven Linux services through DBus and native IPC. Before upgrades, it records the working state; diagnostics remain read-only, and any repair or rollback requires an explicit confirmation and a post-action verification.

SYS.04

AUDIO · CLASSICAL ML · RESEARCH

Cross-lingual speech emotion recognition

PYTHON · AUDIO SIGNAL PROCESSING · ACOUSTIC FEATURES · ML EVALUATION

An interpretable research framework for studying how acoustic features carry across languages. The planned protocol uses speaker-independent partitions across 13 CAMEO corpus splits, then holds Polish nEMO outside training for a clean cross-language evaluation.

13 corpus splits 8 languages nEMO held-out target
Deep architecture note

The feature plan covers MFCCs, pitch, energy, spectral shape, and voice-quality descriptors. Split manifests are frozen by speaker before modeling; learned preprocessing is fit on training data only, and the target-language test set is evaluated once.
